    Apparition du relief
    Comment le logo est dessiné ? Les points de contrôle

    Le logo est composé de deux formes superposées et du texte « DMS » au centre du canvas, modifiable avec les commandes ci-dessus. Tout part de cinq points, calculés à partir de la taille du canvas (W = H = 500) et d'une marge M de 20 px :

    • A : x = 500 − 20, y = 500 − 20
    • B : x = 20, y = 500 − 20
    • C : x = 500 / 2, y = 20
    • D : x = 500 − 20, y = 20
    • E : x = 500 / 2, y = 500 − 20
    const A = { x: W - M, y: H - M };
const B = { x: M,     y: H - M };
const C = { x: W / 2, y: M };
const D = { x: W - M, y: M };
const E = { x: W / 2, y: H - M };
    Effacer, colorer, tracer et ajouter du relief

    On commence par effacer le canvas, puis on règle la couleur de remplissage, la couleur et l'épaisseur du trait, et enfin l'ombre qui donne l'effet de relief (flou fixe, décalage choisi avec le curseur, supprimée si le relief est désactivé).

    ctx.clearRect(0, 0, W, H);

ctx.fillStyle = state.color;
ctx.strokeStyle = '#5034e0';
ctx.lineWidth = state.lineWidth;

ctx.shadowColor = state.relief ? 'rgba(0, 0, 0, 0.5)' : 'transparent';
ctx.shadowBlur = 5;
ctx.shadowOffsetX = state.reliefSize;
ctx.shadowOffsetY = state.reliefSize;
    La première forme (en violet)

    Une ligne du point A au point B, une autre de B à C, puis une courbe de Bézier pour revenir en A en prenant D et E comme premier et second points de contrôle. closePath() referme la forme proprement, puis fill() la remplit et stroke() dessine son contour.

    ctx.beginPath();
ctx.moveTo(A.x, A.y);
ctx.lineTo(B.x, B.y);
ctx.lineTo(C.x, C.y);
ctx.bezierCurveTo(D.x, D.y, E.x, E.y, A.x, A.y);
ctx.closePath();
ctx.fill();
ctx.stroke();
    La seconde forme (en rose)

    On change d'abord la couleur de remplissage pour du rose. Même départ (A vers B), puis une autre courbe de Bézier pour retourner en A, cette fois avec C et B comme points de contrôle.

    ctx.fillStyle = '#e034b3';
ctx.beginPath();
ctx.moveTo(A.x, A.y);
ctx.lineTo(B.x, B.y);
ctx.bezierCurveTo(C.x, C.y, B.x, B.y, A.x, A.y);
ctx.closePath();
ctx.fill();
ctx.stroke();
    Le texte « DMS »

    Les quatre premières lignes règlent la couleur (blanc), la police et la taille, puis l'alignement horizontal et vertical. fillText() écrit le texte au centre du canvas. Les lettres supprimées avec le champ de saisie sont simplement filtrées avant l'écriture.

    ctx.fillStyle = '#ffffff';
ctx.font = `${Math.floor(W / 3 - W / 10)}px serif`;
ctx.textAlign = 'center';
ctx.textBaseline = 'middle';
ctx.fillText(label, W / 2, H / 2);
