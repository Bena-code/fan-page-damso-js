la fonction Javascript pour dessiner le logo : 

    function draw() {
        ctx.clearRect(0, 0, canvas.width, canvas.height);
      
        ctx.fillStyle = colorri.value;
        ctx.strokeStyle = "#5034e0";
        ctx.lineWidth = choix.value;
      
        ctx.shadowColor = 'rgba(0, 0, 0, 0.5)';
        ctx.shadowBlur = 5;
        ctx.shadowOffsetX = slider.value;
        ctx.shadowOffsetY = slider.value;
        if(!check)
          ctx.shadowColor = 'transparent';
      
        ctx.beginPath();
        ctx.moveTo(500-20, 500-20);
        ctx.lineTo(20, 500-20);
        ctx.lineTo(500/2, 20);
        ctx.bezierCurveTo(500-20, 20, 500/2, 500-20, 500-20, 500-20);
        ctx.lineTo(20, 500-20);
        ctx.fill();
        ctx.stroke();
        ctx.closePath();
        ctx.fillStyle = "#e034b3";
        ctx.beginPath();
        ctx.moveTo(500-20, 500-20);
        ctx.lineTo(20, 500-20);
        ctx.bezierCurveTo(500/2, 20, 20, 500-20, 500-20, 500-20);
        ctx.lineTo(20, 500-20);
        ctx.fill();
        ctx.stroke();
        ctx.closePath();
      
        ctx.fillStyle = "#ffffff";
        ctx.font = Math.floor((500/3)-(500/10))+'px serif';
        ctx.textAlign = 'center';
        ctx.textBaseline = 'middle';
        ctx.fillText(texte, (500/2), 500/2);
        texte = "DMS";
      }

Le logo est composé de deux forme superposées et de l'ecriture "DMS" au centre du canvas modifiable avec le menu GUI.

Les points de contrôle :

  • A defini par : x=500-20 et y=500-20
  • B defini par : x=20 et y=500-20
  • C defini par : x=500/2 et y=20
  • D defini par : x=500-20 et y=20
  • E defini par : x=500/2 et y=500-20

Le code si dessous permet de clear, de mettre de l'ombre et tracer les lignes avec les valeurs choisis :

    ctx.clearRect(0, 0, canvas.width, canvas.height);
      
    ctx.fillStyle = colorri.value;
    ctx.strokeStyle = "#5034e0";
    ctx.lineWidth = choix.value;
  
    ctx.shadowColor = 'rgba(0, 0, 0, 0.5)';
    ctx.shadowBlur = 5;
    ctx.shadowOffsetX = slider.value;
    ctx.shadowOffsetY = slider.value;
    if(!check)
      ctx.shadowColor = 'transparent';

La 1er ligne clear le canvas ,ensuite viens la couleur de remplissage et le choix du nombre de pixel pour les lignes. Enfin nous avons le flou


Le code suivant permet de dessiner la première forme du logo (en violet)

    ctx.beginPath();
  ctx.moveTo(500-20, 500-20);
  ctx.lineTo(20, 500-20);
  ctx.lineTo(500/2, 20);
  ctx.bezierCurveTo(500-20, 20, 500/2, 500-20, 500-20, 500-20);
  ctx.lineTo(20, 500-20);
  ctx.fill();
  ctx.stroke();
  ctx.closePath();

Les ligne entre ctx.beginPath(); et ctx.closePath(); servent a tracer un ligne du partant du point A jusqu'au point B et une autre du point B jusqu'au point C, et trace ensuite une courbe de Bézier pour retourner au point A en prenant les point D et E respectivement comme 1er et second points de contrôle. Finalement on retrace une ligne allant du point A au point B afin d'obtenir des angles propres. Les lignes ctx.fill(); et ctx.stroke(); vont respectivement remplir et dessiner les contours de la forme que l'on viens de dessiner avec les caratéristiques définies plus tôt.

ensuite le code suivant dessine la seconde forme (en rose): 

    ctx.fillStyle = "#e034b3";
    ctx.beginPath();
    ctx.moveTo(500-20, 500-20);
    ctx.lineTo(20, 500-20);
    ctx.bezierCurveTo(500/2, 20, 20, 500-20, 500-20, 500-20);
    ctx.lineTo(20, 500-20);
    ctx.fill();
    ctx.stroke();
    ctx.closePath();

Au début, l'instruction ctx.fillStyle = "#e034b3";, va changer la couleur de remplissage pour du rose.

Les ligne entre ctx.beginPath(); et ctx.closePath(); commencent par tracer , comme la 1er figure une ligne du point A au point B , puis une autre courbe de Bézier pour retourner au point A en prennant les points C et E pour points de contrôle. Enfin on retrace une ligne du point A au point B pour des angles propres.Et les lignes ctx.fill(); et ctx.stroke(); vont respectivement remplir et dessiner les contours de la forme que l'on viens de dessiner avec les caratéristiques comme la 1er figure.

Pour finir le code suivant ecrit les lettres au centre du canvas (DMS)

    ctx.fillStyle = "#ffffff";
  ctx.font = Math.floor((500/3)-(500/10))+'px serif';
  ctx.textAlign = 'center';
  ctx.textBaseline = 'middle';
  ctx.fillText(texte, (500/2), 500/2);
  texte = "DMS";

Les 4 première lignes servent à paramétrer respectivement la couleur de remplissage (blanc), la police et la taille du texte à dessiner ainsi que l'alignement vertical et horizontal du texte. Enfin ctx.fillText(texte, (500/2), 500/2); permet d"écrire le texte à l'emplacement souhaité
