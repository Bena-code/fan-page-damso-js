# Site Fan Damso - Web App Musicale 🎵

Site web responsive dédié à l'artiste Damso, intégrant une consommation d'API REST en temps réel.

## 🚀 Fonctionnalités
* **Moteur de recherche musical :** Connexion à l'API publique de **Deezer** pour rechercher des artistes et écouter des extraits (30s) en direct.
* **Architecture technique :** Utilisation de **JSONP** pour contourner les restrictions CORS en local (sans serveur backend).
* **Dessin vectoriel :** Module `<canvas>` interactif avec manipulation de courbes de Bézier (Logo DMS).
* **Formulaire complet :** Validation des données côté client (HTML5 + JS).

## 🛠️ Stack Technique
* **Frontend :** HTML5, CSS3, JavaScript (Vanilla).
* **API Externe :** Deezer API.
